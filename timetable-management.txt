🔐 Key Features Mapped to Code
Feature	Path/Code
Role-Based Login (Admin, HOD, Faculty)	authController.js, roleMiddleware.js, AuthContext.jsx
Elective Preferences	ElectivePreference.js, courseController.js, ElectiveSubmission.jsx
Timetable with Constraints	constraintsChecker.js, timetableController.js, TimetableBuilder.jsx
Workload Calculation	workloadController.js, WorkloadReport.jsx
Reports for Audit	reportGenerator.js, AuditReports.jsx
Real-Time Dynamic Course Availability	WebSocket or polling in courseService.js

📦 Recommended Tech Stack
Frontend: React, Tailwind CSS, React Router, Axios

Backend: Node.js, Express.js, JWT, bcrypt

Database: MongoDB (with Mongoose)

Utilities:

pdfkit / exceljs (for reports)

socket.io (optional for real-time updates)
